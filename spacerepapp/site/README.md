# site/ — материалы для сайта приложения

Здесь лежат документы для будущего сайта (страницы под поисковые запросы). Само приложение и сборка сайта-PWA
(`web/`, `dist/`) сюда не относятся.

| Файл | Что это |
|---|---|
| `cluster-queries.xlsx` | Главный документ (первым идёт лист «0.Статус и что дальше»: что сделано, что осталось, как повторить). Листы 3-5: новые кластеры и идеи, все данные Semrush, подсказки Google. Лист «1.Потребности»: какие потребности закрывает приложение, какая страница под какую, приоритет. Лист «2.Кластеры»: 37 запросов в 7 кластерах и 15 сабкластерах, объём, KD, что даёт первая страница Google, гипотеза «чем наш сайт лучше». Формат листа повторяет образец `howtorelax.now_final.xlsx` (лист 3.Кластеры). |
| `data/semrush-keyword-magic-us-2026-11-07.csv` | Сырые выгрузки Semrush Keyword Magic Tool (США, 07.11.2026): десять строк с самым большим объёмом на каждое зерно. По большинству ваших 17 запросов здесь данных нет, в таблице они стоят как в вашем списке (пять я нашёл и в Magic Tool, там числа свежее). |
| `data/serp-google-us-2026-11-07.md` | Первая страница Google США по каждому из 37 запросов: домен, заголовок, тип ссылки. |
| `cluster-ideas.md` | Те же кластеры и идеи текстом: подтверждённые Semrush, новые (Gemini, ChatGPT, подсказки Google, мои), что проверено и что нет. |
| `data/google-autocomplete-us-2026-11-08.md` | Подсказки Google по 18 зёрнам. |
| `data/serp_data.py` | Те же данные в виде кода (источник для xlsx и md). |
| `data/build_clusters.py`, `data/extra_sheets.py` | Генератор: `python site/data/build_clusters.py` пересобирает xlsx и md. Запросы, объёмы, KD и гипотезы — в нём. |

## Как собраны данные

- **Объём и KD.** Semrush, база США. Для найденных мной запросов — Keyword Magic Tool, 07.11.2026; для запросов из
  вашего списка — ваши числа (там, где я нашёл тот же запрос в Magic Tool, взяты свежие: у `vocabulary games` KD 41
  вместо 46, у `vocabulary word games` KD 12 вместо 34). Бесплатный аккаунт Semrush показывает по десять строк на
  поиск, поэтому в выборку попали верхушки каждой темы, а не все хвосты.
- **Первая страница Google.** Снята из Chrome по адресу `google.com/search?q=...&gl=us&hl=en&pws=0`, 7-9 органических
  ссылок на запрос (блоки «Люди также спрашивают», видео и реклама не вошли). Тип ссылки (играть сразу, поставить
  приложение, читать) размечен мной по домену и заголовку; страницы не открывались. Если на странице выдачи важна
  точность, разметку надо перепроверить глазами.
- **Это не Semrush SERP Analysis**, как в образце: я им не пользовался, дневной лимит бесплатных аккаунтов ушёл на поиск объёмов. Google отдаёт ту же выдачу, но без метрик ссылок (трафик, обратные ссылки).

## Что не подтверждено

- Заявления про приложение в гипотезах взяты из README, описания магазина и кода. Про японский и корейский отдельно
  не проверено, как приложение рисует иероглифы и хангыль в Snake и Wordcraft.
- Про конкурентов (бесплатно ли у них, реклама, подписка) в гипотезах стоят только факты из заголовков выдачи; цены и
  условия перед публикацией страниц сравнения надо проверять на их сайтах.
